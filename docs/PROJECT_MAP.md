# Project Map

## Level 0 — Project

Governed Spec-Driven Development (`gsd`)

## Components

| Component | Name | Purpose |
|---|---|---|
| C1 | Governance Doctrine | Core GSD method and rationale |
| C2 | Base Templates | Reusable docs and governance templates |
| C3 | Spec Templates | Feature spec, plan, task, tranche, validation templates |
| C4 | Domain Presets | Mission-specific policies such as clinical safety |
| C5 | Agent Instructions | Agent-facing prompts and instruction files |
| C6 | CLI Bootstrapper | Bash command for repo initialization and workflows |
| C7 | Agent Adapters | Codex, Claude, Copilot, Cursor, generic adapters |
| C8 | Spec Kit Bridge | Optional Spec Kit-compatible integration |
| C9 | Validation Tooling | Checks, tests, CI, golden files |
| C10 | Examples | Reference greenfield and brownfield projects |
| C11 | Release Management | Versioning, changelog, packaging |
| C12 | Security and Privacy | Secret handling, PII/PHI controls, safe examples |
