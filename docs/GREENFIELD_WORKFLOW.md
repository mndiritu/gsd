# Greenfield Workflow

Use this workflow when starting a new project.

## Sequence

1. Create repository.
2. Create `AGENTS.md`.
3. Create governance docs.
4. Define domain preset.
5. Define project phases.
6. Define initial components.
7. Define risk model.
8. Define testing/validation policy.
9. Create first specification.
10. Clarify assumptions.
11. Create plan.
12. Generate tasks.
13. Convert tasks to tranches.
14. Implement only approved tranche.
15. Validate.
16. Log.
17. Update resume marker.

## Agent instruction

Before writing functional code, create or confirm:

- documentation policy;
- roadmap;
- project map;
- risk register;
- testing policy;
- implementation log;
- resume marker.
