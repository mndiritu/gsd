# Specs Directory

Feature specifications live here.

Each feature should use this structure:

```text
specs/
  001-feature-name/
    spec.md
    clarify.md
    plan.md
    tasks.md
    tranches.md
    risk.md
    validation.md
    closeout.md
```

Specs may be produced directly by GSD templates or bridged from Spec Kit-compatible workflows.
